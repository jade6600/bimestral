Proceso de trabajo

Del proyecto a la atención profesional

El sitio permite gestionar las solicitudes de los clientes mediante un proceso organizado.

PASO 01

Crear una cuenta

El cliente registra sus datos para poder acceder a las funciones de la plataforma.

PASO 02

Seleccionar un servicio

El cliente consulta los servicios profesionales disponibles y selecciona el que necesita.

PASO 03

Enviar una solicitud

El cliente proporciona la información necesaria sobre su proyecto y envía la solicitud.

PASO 04

Revisión de la solicitud

La solicitud es revisada para determinar las características y necesidades del proyecto.

PASO 05

Atención profesional

Se establece la comunicación necesaria para desarrollar el servicio solicitado.

PASO 06

Calificación del servicio

Una vez finalizado el servicio, el cliente podrá realizar una valoración.
